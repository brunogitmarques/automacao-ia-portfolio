# Agente Inteligente de Consulta de Pedidos

## Objetivo
Desenvolver um agente de IA capaz de consultar informações de pedidos e responder às solicitações dos clientes de forma automatizada.

## Funcionalidades
- Identificação do cliente por e-mail.
- Consulta de pedidos.
- Busca por identificador do pedido.
- Retorno do status de entrega.
- Consulta de produtos e valores.
- Respostas em linguagem natural.

## Tecnologias utilizadas
- n8n
- Inteligência Artificial (LLM)
- Google Sheets
- Automação de processos

## Benefícios
- Redução de consultas manuais.
- Agilidade no atendimento.
- Centralização das informações.
- Melhor experiência para o cliente.

## Status
Projeto desenvolvido para fins de demonstração e portfólio.
